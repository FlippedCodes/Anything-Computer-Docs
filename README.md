## Wow these docs look so cool and amazing, what framework are you using?

Dang these questions are getting long...

I use a heavily modified [Docsify](https://docsify.js.org/#/), with plugins, custom CSS and markdown files. I have been writing with this Markdown-Framework for a while and I like how open it is to modifications along side with other features, which I have not seen on others.

If docs aren't fun to write... no one wants to do it anymore. And since im a power user, the app needs to fit my workflow, the best it can, not the other way around.
